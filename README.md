# TrustVault Role-Based Security System

A secure, zero-knowledge backend framework built with **Python (FastAPI)** enforcing strict authorization matrix bounds across Owner, Admin, and Viewer roles.

## 🚀 Quick Local Installation & Boot Launch
1. Ensure dependencies are satisfied on your terminal workspace:
   ```bash
   pip install fastapi uvicorn pytest requests
   ```
2. Fire up the localized backend server environment engine:
   ```bash
   python -m uvicorn main:app --reload
   ```
3. Open your internet browser interface to access the auto-generated documentation evaluation playground:
   👉 **http://127.0.0**
